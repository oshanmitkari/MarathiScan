### 2️⃣ **How does it format the OCR text into DOCX?**

**Structure:**
```
┌─────────────────────────────────┐
│  OCR Extracted Document         │  ← Title (Bold, 20pt)
│  Generated by ScanDoc           │  ← Subtitle (Italic, 12pt)
├─────────────────────────────────┤
│  ─────── Page 1 ───────         │  ← Page Header (Bold, 14pt)
│  [OCR text from page 1]         │  ← Content (11pt)
├─────────────────────────────────┤
│  ─────── Page 2 ───────         │  ← Page Header (Bold, 14pt)
│  [OCR text from page 2]         │  ← Content (11pt)
└─────────────────────────────────┘
```

**Technology:** Apache POI library (`XWPFDocument`, `XWPFParagraph`, `XWPFRun`)

---

### 3️⃣ **What font is used for Marathi text?**

**Font:** `"Noto Sans Devanagari"`

**Why?**
- ✅ Universal support (Windows, macOS, Linux, Android)
- ✅ Designed for Devanagari script (Marathi, Hindi, Sanskrit)
- ✅ Open source and free
- ✅ High-quality rendering

**Applied to:** ALL text in the document (title, headers, content)

---

### 4️⃣ **Where is the exported file saved?**

**Android 10+ (API 29+):**
```
/storage/emulated/0/Android/data/com.mk.scandoc/files/Documents/ScanDoc/
```

**Android 9 and below:**
```
/storage/emulated/0/Download/ScanDoc/
```

**Filename:** `ScanDoc_OCR_[timestamp].docx`  
**Example:** `ScanDoc_OCR_1738337520123.docx`

## 🔧 TECHNICAL DETAILS

### **Libraries Used:**
- Apache POI 5.2.3 (`org.apache.poi:poi-ooxml`)

### **Key Classes:**
- `XWPFDocument` - Main document object
- `XWPFParagraph` - Paragraph container
- `XWPFRun` - Text run with formatting

### **File Format:**
- DOCX (Office Open XML)
- UTF-8 encoding
- Devanagari font embedded in style

### **Permissions Required:**
- Android 10+: No special permission (scoped storage)
- Android 9-: `WRITE_EXTERNAL_STORAGE`
