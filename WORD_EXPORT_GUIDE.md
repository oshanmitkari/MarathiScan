## 📚 PART 1: UNDERSTANDING THE WORD EXPORT PROCESS

### 🔍 **1. Which Method Handles the Word Export?**

**File:** `PagesFragment.java`  
**Main Methods:**

1. **`exportWord()`** (Lines 775-793)
   - Entry point when user clicks "Export Word DOCX" button
   - Validates that OCR data exists
   - Checks storage permissions
   - Calls `exportWordDocument()` if ready

2. **`exportWordDocument()`** (Lines 795-935)
   - Main export logic
   - Creates the DOCX file using Apache POI library
   - Formats the OCR text
   - Saves the file to device storage

### 🔤 **3. What Font is Used for Marathi Text?**

**Font:** `"Noto Sans Devanagari"`

**Why This Font?**
- ✅ **Universal Support:** Available on Windows, macOS, Linux, Android
- ✅ **Devanagari Script:** Specifically designed for Marathi, Hindi, Sanskrit
- ✅ **Open Source:** Free to use, no licensing issues
- ✅ **High Quality:** Clear rendering of complex Devanagari glyphs

**Applied To:**
- Title text (Line 827)
- Subtitle text (Line 834)
- Page headers (Line 846)
- OCR content (Line 851, 871)
- Empty page markers (Line 871)

**Fallback Behavior:**
If "Noto Sans Devanagari" is not available on the device opening the DOCX:
- Windows: Falls back to "Mangal" (built-in Devanagari font)
- macOS: Falls back to system Devanagari font
- Android: Falls back to system default

## 🧪 PART 2: TESTING THE WORD EXPORT

### ✅ **Step-by-Step Testing Instructions**

#### **Step 1: Ensure OCR Has Been Run**
1. Open ScanDoc app
2. Go to **"Scan"** tab
3. Scan a document with Marathi and/or English text
4. Go to **"Pages"** tab
5. Click **"Run OCR"** button
6. Wait for OCR to complete (you'll see extracted text in the list)

#### **Step 2: Export to Word**
1. In the **"Pages"** tab, click **"Export Word DOCX"** button
2. Button text changes to **"Exporting..."**
3. Wait for export to complete (usually 1-3 seconds)
4. You'll see a success message with:
   - Number of pages with text
   - File location path

#### **Step 3: Locate the Exported File**

**Option A: Using File Manager App**
1. Open your phone's **File Manager** app
2. Navigate to:
   - **Android 10+:** `Android/data/com.mk.scandoc/files/Documents/ScanDoc/`
   - **Android 9-:** `Download/ScanDoc/`
3. Look for file: `ScanDoc_OCR_[timestamp].docx`

**Option B: Using ADB (for developers)**
```bash
adb shell ls -lh /storage/emulated/0/Android/data/com.mk.scandoc/files/Documents/ScanDoc/
```
